# Caterpillar Dashboard

A complete React Admin Dashboard application featuring Material UI, Data Grid, light & dark modes, Telegram API integration, and OpenAI-powered AI features.

---

## Features

- **Modern React Admin Interface**  
  Built with React and Material UI for a responsive, professional look and feel.

- **Data Grid Integration**  
  Advanced data tables for displaying and managing large datasets efficiently.

- **Light & Dark Mode**  
  Instantly toggle between light and dark themes for optimal viewing comfort.

- **Telegram API Integration**  
  Connects with Telegram to enable messaging or bot functionalities directly from the dashboard.

- **OpenAI AI Integration**  
  Leverage OpenAI's capabilities for smart features such as text generation, chat, or analytics.

- **Customizable & Extensible**  
  Easily adapt the dashboard to your needs with modular components and flexible design.

---

## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Than1612/caterpillar_dashboard.git
   cd caterpillar_dashboard
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Set up environment variables**  
   Configure your API keys (Telegram, OpenAI, etc.) as required in a `.env` file.

4. **Start the development server**
   ```bash
   npm start
   # or
   yarn start
   ```

5. **Access the dashboard**  
   Open your browser and go to `http://localhost:3000/`.
